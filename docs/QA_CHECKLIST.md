## 자동 검사

```
npm run check   # 타입 검사 + 단위 테스트 + 금지어 검사("치료", "진단", "점수", "분석" 등)
```

## 날짜 시나리오 테스트 (개발 서버에서만)

`npm run dev`로 띄운 뒤 주소 뒤에 `?debugDate=YYYY-MM-DD`를 붙이면 그 날짜를 오늘로 간주합니다.
배포 빌드에서는 동작하지 않습니다.

- 다음 날: `http://localhost:5173/?debugDate=2026-10-05#/home` → 새 질문이 열리고 "답하기"가 보인다
- 며칠 뒤: `?debugDate=2026-10-10` → 반가운 인사 연출, 부정적 문구 없음
- 앨범: 여러 날짜로 기록한 뒤 최신 날짜가 위에 오는지, 건너뛴 날은 아무 표시도 없는지 확인
